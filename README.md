The idea is to build a chatbot for Telegram and WhatsApp using Python and Django. This chatbot will be able to convert voice to text and text to voice.

To achieve this, I’ll use:

    Python + Django as the core framework
    PostgreSQL as the database
    Docker and Docker Compose to containerize the application and run it locally

This will be my first post, and throughout the blog I’ll explain not only what I’m building but also how I’m building it. My goal is to document the journey and share what I learn along the way.
